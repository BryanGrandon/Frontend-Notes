# 🧠 Programming Logic

Programming logic is the fundamental foundation of software development. It allows us to analyze problems, structure solutions, and translate them into clear and ordered instructions that a computer can execute. Mastering these concepts is essential before diving into any programming language.

## 📦 Data Structures

Data structures allow us to organize, store, and manipulate information efficiently. Choosing the right structure directly impacts performance and code clarity.

Some fundamental data structures include:

- Variables and constants
- Arrays
- Lists
- Stacks
- Queues
- Sets and maps

---

## 🔄 Algorithms

An algorithm is a finite and ordered set of steps used to solve a problem or perform a specific task.

Main characteristics of a good algorithm:

- Clear and precise
- Finite
- Efficient
- Reusable

Common algorithm examples include:

- Searching (linear, binary)
- Sorting (bubble, selection, insertion)
- Mathematical and logical algorithms

---

## ⏱️ Algorithmic Complexity

Algorithmic complexity measures the resources an algorithm consumes, mainly:

- Time (how fast it runs)
- Space (how much memory it uses)

It is commonly expressed using Big O notation, for example:

- O(1) — constant time
- O(n) — linear time
- O(n²) — quadratic time

Analyzing complexity helps compare solutions and choose the most efficient one.

## 🔁 Recursion

Recursion is a technique where a function calls itself to solve a problem by breaking it down into smaller sub-problems.

- Every recursive algorithm must have:
- A base case (stopping condition)
- A recursive case

It is commonly used in:

- Factorial calculations
- Fibonacci sequence
- Traversing hierarchical structures (trees)

---

## 🧩 Dynamic Programming

Dynamic programming is an optimization technique for recursion that avoids repeated calculations by storing intermediate results.

It is based on two core ideas:

- Overlapping sub-problems
- Optimal substructure

There are two main approaches:

- Memoization (top-down)
- Tabulation (bottom-up)

It is widely used in optimization problems and advanced algorithms.
